Introduction to NexaFlow

You're reading the NexaFlow 3.0 documentation. Looking for older versions? View v2.x docs →

NexaFlow is an AI-powered workflow automation platform that lets you connect any tools, automate any process, and deploy intelligent agents — without writing backend infrastructure code.

With NexaFlow you can:

  • Build automation workflows with a visual drag-and-drop canvas
  • Connect 300+ services through native integrations
  • Deploy AI agents that reason and adapt to real-world situations
  • Execute millions of workflows per day with sub-millisecond latency
  • Monitor everything with real-time observability and analytics

Quick Start

Get your first workflow running in under 5 minutes.

1. Create your account

Sign up at nexaflow.ai/signup. You'll start on a 14-day Pro trial — no credit card needed.

2. Connect your first integration

From the dashboard, go to Integrations → Add Connection. Search for your service (Slack, GitHub, Stripe, etc.) and follow the OAuth prompts.

3. Create a workflow

Click + New Workflow. The visual builder opens. Drag a trigger node from the left panel and drop it on the canvas. Then add action nodes and connect them with wires.

JavaScript — Custom Code Node 
// Custom code nodes have access to all input data
const { customer, payment } = $input.data;

// Enrich with external API
const enriched = await $http.get(`https://api.clearbit.com/v2/people/find?email=${customer.email}`);

// Return data for the next node
return {
  customer: { ...customer, ...enriched.data },
  paymentAmount: payment.amount / 100,
  isHighValue: payment.amount > 100000
};

Core Concepts

Workflows

A workflow is a sequence of connected steps that execute in response to a trigger. Workflows can be simple (A → B) or complex (parallel branches, loops, human approval gates).

Nodes

Nodes are the building blocks of a workflow. Each node performs a single action: sending a message, querying a database, calling an API, running AI inference, or executing custom code. Nodes are connected by wires that pass data between them.

Triggers

Every workflow starts with a trigger. Triggers include:

  • Webhook — An HTTP POST to a generated endpoint URL
  • Schedule — Cron-based timing (every hour, every Monday at 9am, etc.)
  • Event — A specific event from a connected integration (new Slack message, GitHub PR opened, etc.)
  • Manual — Triggered by clicking a button in the NexaFlow UI
  • API — Triggered by calling the NexaFlow REST API

Executions

Each time a workflow runs, that's an execution. You can view every execution in the Executions log — including input data, output data, duration of each step, and any errors that occurred.

Executions count toward your monthly plan limit. Check your usage in Settings → Billing.

API Authentication

All NexaFlow API requests require an API key. Generate one in Settings → API Keys.

Shell — cURL 
# Trigger a workflow via the API
curl -X POST https://api.nexaflow.ai/v1/workflows/wf_abc123/trigger \
  -H "Authorization: Bearer nf_sk_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"customer_id": "cust_456", "event": "payment_completed"}'
TypeScript — SDK 
import { NexaFlow } from '@nexaflow/sdk';

const nf = new NexaFlow({ apiKey: process.env.NEXAFLOW_API_KEY });

// Trigger a workflow
const execution = await nf.workflows.trigger('wf_abc123', {
  customer_id: 'cust_456',
  event: 'payment_completed'
});

console.log(execution.id); // exec_789xyz

// Wait for completion
const result = await execution.waitForCompletion();
console.log(result.output); // { success: true, ... }

Workflows API

GET /v1/workflows

Returns a paginated list of all workflows in your workspace.

POST /v1/workflows/{id}/trigger

Triggers a workflow execution with optional input data. Returns the execution object.

GET /v1/executions/{id}

Returns a single execution by ID, including step-level trace data.

DELETE /v1/workflows/{id}

Permanently deletes a workflow and all its execution history. This action is irreversible.
